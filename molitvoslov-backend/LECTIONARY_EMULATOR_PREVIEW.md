# Чтения 2027 — пробный просмотр на Android-эмуляторе

## Что добавлено

- Отдельная **dev-only** панель в `ChurchCalendarScreen`: кнопка **Показать предварительные чтения 2027**.
- Встроенный read-only JSON `molitvoslov-app/src/data/lectionaryPreview2027.json`. Данные не требуют интернета, Django или импорта в SQLite.
- 365 дат, 262 дня с хотя бы одним чтением, 103 дня пока без чтений. **456 из 459 назначений — непроверенные кандидаты**.
- Каждое назначение показывает вид, ссылку, статус, а нажатие открывает начало соответствующего фрагмента в существующем экране Библии. Для составного чтения каждый фрагмент открывается отдельно.
- Отдельная безопасная Django-команда `generate_lectionary_preview` для получения нового диагностического JSON из локальных чтений 2026 года.

## Проверить на Windows

```powershell
cd C:\m\repo
git status
git fetch origin
git switch --track origin/feature/lectionary-emulator-preview
cd .\molitvoslov-app
npx expo start --android --clear
```

Если ветка уже создана локально, вместо `git switch --track`:
```powershell
git switch feature/lectionary-emulator-preview
git pull --ff-only
```

В Android-эмуляторе: открыть **Календарь** → нажать **Показать предварительные чтения 2027**. Приложение переключит календарь на **2 мая 2027** (Пасха). На этой дате предусмотрены:
- Деян. 1:1–8
- Ин. 1:1–17
- Ин. 20:19–25 (вечерня)

Проверить нажатие на каждую ссылку; листать календарь по месяцам и выбирать другие дни. Кнопка видна **только в dev-сборке** (`__DEV__`).

## Генерировать новые годы (без записи в базу)

```powershell
cd C:\m\repo\molitvoslov-backend
& .\venv\Scripts\python.exe manage.py generate_lectionary_preview --year 2028
```

Команда использует **локальные** `CalendarDay`/`CalendarReading` за 2026 год (нужны полные 365 дней) и формирует `lectionary_preview_2028.json` с явно непроверенными назначениями. **Она не делает календарь 2028 автоматически доступным в UI** — текущая dev-панель показывает отдельно приложенный предварительный JSON за 2027 год.

## Ограничения, которые принципиально нельзя скрывать

- Это **не полный проверенный Типиконом лекционарий**. Не готовы уставные правила отступки/преступки, переход к Луке, чтения при совпадении праздников, все службы Великого поста, Страстной недели и другие исключения.
- 1114 ссылок справочника прошли проверку существования книг, глав и стихов в локальной Библии, **но это не равно проверке уставных границ**. Остаются расхождения в вариантах границ чтений.
- Даты, где нет рассчитанных чтений, остаются пустыми.
- Панель предпросмотра **не заменяет** штатные показания календаря.
- Ничего не меняется в SQLite, Supabase и API; никаких миграций.
- Для составных многокнижных чтений можно открыть начало **каждого фрагмента**, но текущий общий экран Библии пока не выделяет сразу все раздельные диапазоны.

Когда алгоритм будет дополнен таблицами Устава и проверен по независимому календарю, можно будет подключать готовые годовые чтения к `CalendarReading`. До этого импорт запрещён.
