# Проверка календарных чтений 2027 — защитный комплект

Этот комплект НЕ перезаписывает чтения и НЕ утверждает, что все 365 дней уже проверены на сайте. Он добавляет проверку неправильной даты ответа и две независимые проверки уже записанной базы.

## Установка

1. Распаковать ZIP.
2. В `C:\m\repo\molitvoslov-backend` запустить:

```powershell
python <путь-к-распакованной-папке>\install_readings_guard.py C:\m\repo\molitvoslov-backend
```

3. Скопировать `audit_2027_readings.py` и `verify_2027_readings.py` в `C:\m\repo\molitvoslov-backend\api\management\commands\`.

4. В активированном venv из папки backend выполнить:

```powershell
python manage.py audit_2027_readings --year 2027
python manage.py verify_2027_readings --year 2027
```

Первая проверка локальная и быстрая. Вторая проверяет **все 365 дат** на сайте (длительная) и сохраняет расхождения. Она не изменяет базу и не удаляет уже импортированные чтения.

## Что диагностируется

- DATE_MISMATCH: ответ перенаправлен на иную дату либо canonical/og:url указывает другой день; импорт блокируется.
- MISSING_DAY: день отсутствует.
- NO_READINGS: нет ни одной записи чтения.
- MAIN_NOT_IN_FEASTS: главное празднование не входит в связи дня.
- EXACT_DUPLICATE, EMPTY_READING_TITLE: явные дефекты чтений.
- DIFFERENT: чтения в SQLite не совпадают с текущим разбором источника.
- SOURCE_ERROR: источник не удалось проверить; не следует считать данные корректными или неверными автоматически.

**Особые дни Великого канона:** без подтверждённых чтений нельзя автоматически вставлять соседние либо сохранять неотносящиеся к дате ссылки. Это остаётся источниковым исключением до богослужебной проверки.

## Важные ограничения

Защита URL и canonical не доказывает соответствие текста каноническому расписанию, когда сайт отдаёт неверное содержимое с правильным URL. Сверка с тем же источником не является независимым богослужебным эталоном. Проверка проводится без удаления ручных правок.

Установщик проверяет ожидаемую структуру исходника и создаёт `.bak_...` перед изменением; если код другой версии, он останавливается без правок. Не запускайте массовый `--overwrite` до рассмотрения отчёта.
