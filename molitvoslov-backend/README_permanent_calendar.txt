МОЛИТВОСЛОВ — ПОСТОЯННЫЙ СПРАВОЧНИК И ГЕНЕРАТОР

Положить оба файла в C:\m\repo\molitvoslov-backend

Команда PowerShell:
python generate_molitvoslov_year.py --database molitvoslov_permanent_calendar_catalog.json --year 2027

Результат calendar_2027.json — 365 дней с памятями и базовыми периодами постов.
Исходный год не используется как эталон: все даты вычисляются по date_rules.
Юлианские даты рассчитываются по настоящему правилу преобразования календарей.

ОГРАНИЧЕНИЯ:
1. Даты в каталоге взяты из исходных данных и предыдущих корректировок. Автоматическая генерация без ошибок НЕ гарантирует правильность каждого правила источника.
2. Чтения по зачалам не реализованы: поле readings=null.
3. Степени поста (рыба, масло, сухоядение) и все праздничные исключения не реализованы.
4. Главная память выбирается только в однозначном случае единственного великого праздника.
5. Правила приоритета и совмещения памятей не реализованы полностью.
6. Скрипт ничего не изменяет в SQLite / Django.
