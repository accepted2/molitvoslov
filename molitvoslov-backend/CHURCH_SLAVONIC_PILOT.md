## Обновление полного корпуса

Для воспроизводимой генерации в репозитории имеется:

```powershell
cd C:\m\molitvoslov-search
py -3 molitvoslov-app\tools\build_csl_ponomar_bible.py
```

Команда скачивает 77 исходных текстовых файлов из закреплённой ревизии
Ponomar (при наличии Интернета), валидирует номера глав и стихов и
создаёт `offlineBibleCslTraditional.json` и `csl_import_audit.json`.
Результат уже добавлен на GitHub, **для обычного pull запускать команду не нужно**.

Отдельный импортёр Django `import_bible_church_slavonic.py` по-прежнему
рассчитан только на старый HIP-кандидат из `csl.zip` (Бытие, Псалтирь
1–150 и Матфей) и предназначен для внутренних тестов. Он не нужен для полной
офлайн-Библии. Не используйте его экспорт поверх полного JSON.

## Известные ограничения

- В первоисточнике Ponomar имеются пропуски отдельных номеров стихов в
  псалмах 50, 66 и 141; текст при генерации не дополняется вымышленными стихами.
- Из-за отличий церковнославянской и Синодальной стиховой нумерации переход
  между переводами по номеру стиха требует дополнительной проверки, особенно
  в Псалтири и расширенных книгах Ветхого Завета.
- Отображение всех надстрочных символов на конкретной Android-сборке
  необходимо проверить вручную на устройстве.
- Полный JS bundle/APK в CI не собирается из-за отсутствующего у workflow
  исходного `search_seed_v10.db`; синтаксис React Native и Django проверен.

Никогда не перезаписывайте `offlineBible.json` и IDs Синодальной Библии
данными перевода `csl_traditional`.
