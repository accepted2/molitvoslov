Политика конфиденциальности приложения «Молитвослов»

Эта политика относится к мобильному приложению «Молитвослов» и его серверным функциям синхронизации.

Какие данные используются

Без входа через Google тексты и сохранения могут храниться локально на устройстве. При входе обрабатываются идентификатор Google-аккаунта, адрес электронной почты, имя и изображение профиля, переданные Google, а также токен сессии приложения.

При включённой синхронизации сервер получает избранные тексты и фрагменты, закладки, прогресс чтения, помянники, пользовательские молитвы, изображения и настройки чтения. Приложение может хранить локальные технические данные для работы офлайн.

Зачем и где данные обрабатываются

Данные используются для авторизации, восстановления и синхронизации между устройствами. В обработке участвуют Google (вход), сервер приложения на Render и база данных/хранилище Supabase. Данные не предназначены для продажи рекламодателям.

Защита и хранение

Доступ к личным данным через API требует входа; соединения с сервером защищены HTTPS. Личные данные хранятся, пока аккаунт действует и они нужны для предоставления функций. При запросе удаления аккаунта связанные данные удаляются после проверки принадлежности, кроме данных, которые необходимо сохранить на законных основаниях; о таких случаях пользователю сообщается.

Права пользователя, удаление и контакт

Пользователь может удалить отдельные сохранения и запросить удаление всего аккаунта. Запрос доступен в приложении и на отдельной веб-странице, даже после удаления приложения. Через ту же форму можно отправить вопрос по персональным данным. Запрос не выполняется по одному неподтверждённому адресу электронной почты.
