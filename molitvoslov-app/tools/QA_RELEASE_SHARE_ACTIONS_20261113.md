# Молитвослов — проверка APK 1.0.25 (26)

## Сборка и установка на телефон (Windows PowerShell)

```powershell
cd C:\m\molitvoslov-search\molitvoslov-app
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build-release-and-smoke-20261113.ps1 -InstallOnPhone
```

Скрипт проверяет Node-тесты и production JS bundle, при необходимости запускает Expo prebuild, собирает Android release APK, сохраняет копию в `reports/molitvoslov-1.0.25-26.apk`, проверяет SHA256, устанавливает APK на **одно** подключённое устройство через adb и открывает приложение.

Перед запуском: `npm ci` при отсутствующем `node_modules`, Java 17, Android SDK, `adb` и USB-отладка. **Не удалять старое приложение при ошибке подписи:** это может удалить несинхронизированные данные.

## Ручной чек-лист на телефоне

- [ ] Акафисты: поиск справа от заголовка; верхняя шапка по цвету и градиенту совпадает с канонами/другими каталогами
- [ ] Акафисты и каноны в списках: отдельные сердце и значок отправки; тонкая вертикальная граница после стрелки, кнопки не открывают чтение
- [ ] Внутри акафистов и канонов: рядом с сердцем есть отправка конкретного блока; выделение стихов не ломается
- [ ] Кафизма: сердечко и отправка; при нажатии на поделиться идёт сам текст и ссылка, без ожидания создания копии
- [ ] Часы (первый и третий): у заголовков и раскрывающихся частей есть обе кнопки; сохранение отображается в избранном, повторное нажатие удаляет из избранного
- [ ] Утренние/вечерние молитвы: на каждой самостоятельной молитве отдельно сохранить и поделиться
- [ ] Разные молитвы: у опубликованных (не заглушек) молитв обе кнопки с разделителем после стрелки
- [ ] Житие и календарь: уменьшенная вертикальная «⋮»; внутри сохранить/убрать и поделиться
- [ ] Избранное: уменьшенная «⋮», открыть, поделиться, закрепить/открепить, удалить только с подтверждением
- [ ] В избранном сохранённый раздел часов открывает соответствующий час
- [ ] Библия: Ветхий и Новый Завет в RU/ЦС — у книг есть отдельные сердце и поделиться с разделителем после стрелки
- [ ] Библия: из списка глав «⋮» сохраняет главу и отправляет текст без открытия; долгое нажатие также открывает меню
- [ ] Избранное: сохранённые книга и глава открываются в правильном переводе
- [ ] Ссылка с телефона A на телефон B: текст виден в сообщении, ссылка ведёт к исходному месту в приложении
- [ ] Переключение ЦС/RU и масштаб интерфейса не ломает заголовки и кнопки
- [ ] Нет красных экранов React Native или ошибок в LogBox при открытии каждого типа чтения

## Проверка версии и логов

```powershell
adb shell dumpsys package com.accepted2.molitvoslov | Select-String "versionCode|versionName"
adb logcat -d -s ReactNativeJS:V AndroidRuntime:E
```

HTTPS-ссылки с новыми маршрутами стиха/святого требуют публикации обновлённого backend `api/content_share.py` на Render. Передача личных молитвословов и помянников с фотографиями требует обновлённого `api/shared_invitations.py` и настроенного хранилища. Обычное публичное текстовое «Поделиться» не требует сервера.

**Физическая проверка:** выполнять на телефоне с установленной release-сборкой. Серверные сценарии нужно испытывать между двумя аккаунтами/устройствами.
