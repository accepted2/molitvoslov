# Сведение календарных исправлений двух веток · 23.11.2026

**Исходная ветка**: `feat/calendar-alternate-hymns-editor-20261123`.
**Интеграционная ветка**: `integration/calendar-hymns-icons-safe-20261123`.
**Дополнительный источник**: `fix/calendar-blagovest-hymn-variants-integrated-20261123`.

## Что сохранено из параллельной редакторской работы

- Django-модель `CalendarFeast` со всеми существующими RU/UK полями
  `troparion_alternate_*`, `kontakion_alternate_*`.
- Уже существующая **единственная** миграция `0047_calendarfeast_alternate_hymns.py`.
  Конфликтующая миграция `0047_calendarfeast_hymn_variants.py` из другой
  ветки **не переносилась**.
- Редактирование в админке, `manually_edited_fields`, скриптовые
  флаги `civil/csl`, конвертер `calendar_hymn_normalization.py`,
  транзакционная команда `split_calendar_hymns` с backup.
- Жития, даты, посты, Евангелие, Апостол, Притчи и существующие годовые
  JSON из исходной ветки НЕ изменены.

## Что добавлено из другой ветки

- `uocAllCivilHymns0..7.json`: 2 821 вариант тропарей/кондаков для 1 267
  канонических карточек, гражданский/украинский текст по отдельным `variant`.
- `uocCivicHymns210.json`: 210 старых источников UCS и 16 извлечённых
  дополнительных песнопений (226 блоков, оригинал сохранён).
- `calendarCardPresentation.js`: приоритет актуального текста из редактора
  (включая ручную правку), затем исходного гражданского текста, затем
  восстановленных UCS. `_alternate` из нынешней админки совместим
  с `_alt` старой разработческой ветки. Непроверенную шрифтовую
  абракадабру не показывает как гражданский текст.
- Экран дня и экран святого выводят каждый тропарь/кондак отдельно.
- Совместимый дополнительный ответ API: `title_ru`, `title_uk`,
  `hymns[]`, `protected_hymn_fields`, `icon_is_manual`. Существующие
  поля API и модель Django остаются без переименований.

## Иконы из нашего аудита

- Сохранён список **2 734** отдельных кандидатов (одна ссылка на карточку,
  без URL, выбранных для разных святых; мелких миниатюр и восстановленных
  только по догадке ссылок).
- Отдельный карантин содержит **598** назначений из-за повторных URL,
  маленьких изображений и неподтверждённых full-size ссылок.
- Ещё 459 карточек в исходном каталоге без изображения.
- Специально восстановлен один полноразмерный образ Петра и Павла,
  подтверждённый как тот же файл в источниковой галерее.
- Две статьи о святителе Николае связаны с одним образом и
  не показываются двумя разными святыми дня.
- Явно выбранная администратором икона имеет приоритет; даже намеренно
  очищенное ручное поле не заполняется автоматически.
- **Фактическое разрешение пикселей, доступность URL и права публикации не
  утверждены.** Иконки предназначены для просмотра/проверки в приложении;
  нельзя автоматически разрешать ими публичную рассылку в Telegram.

файлов. Для проверки использовать независимую Git worktree и позже
согласовать её с локальными незакоммиченными изменениями.

Никаких автоматических модификаций рабочей SQLite/API, запуска Render,
релиза APK или публикации Telegram этот PR не делает.
