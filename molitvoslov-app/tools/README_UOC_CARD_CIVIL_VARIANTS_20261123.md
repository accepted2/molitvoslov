# Календари УПЦ: одна икона + все варианты песнопений

Ветка `fix/calendar-one-icon-readable-variants-ui-20261123` основана на `fix/calendar-blagovest-civic-only-20261123`. Она независима от параллельной редакторской вычитки житий/тропарей/кондаков.

## Принцип работы

- На одну уникальную память дня показывается одна выбранная `icon_url`. Исходный набор из многих икон не удаляется из базы, но никогда не образует галерею внутри карточки.
- `hymns[]` (kind `tropar`/`kondak`, `variant` 1,2,3...) или поля `troparion_alt_*`/`kontakion_alt_*` показываются **разными раскрывающимися блоками**: «Тропарь», «Иной тропарь», «Кондак», «Иной кондак».
- В первую очередь берём готовую читаемую версию `civil` или проверенную `uk`; raw UCS-8 не публикуется как гражданский текст.
- Если гражданского текста нет, его необходимо подготовить из источника конвертером и проверить. До этого карточка показывает сообщение об отсутствии готового варианта, а не испорченную кириллицу.
- Никакие исправления другого чата поверх существующих вручную изменённых полей этим PR не записываются. Евангелие/Апостол/Ветхий Завет, календарные даты, жития не менялись.


Создаст `reports/uoc-civil-card-manifest-20261123/` с отдельными текстами 1..N, одной выбранной иконой, отчётом неподтверждённых конверсий и контрольной SHA256 исходной SQLite. Команда **не устанавливает** тексты в APK или Django, не вызывает API и не публикует их.

## Важное условие интеграции

Этот PR добавляет **отображение и безопасный выбор**, а не утверждает все импортированные церковнославянские тексты. Новая модель / API и офлайн-пакет должны отдавать подготовленные `hymns[]` или отдельные `*_alt_*` поля. После окончания редакторской очистки следует собрать рабочую ветку с этими полями, затем проверить каждую из 210 неоднозначных записей и 459 карточек без выбранной иконы. Нельзя автоматически заменить отсутствующую икону чужим изображением.
