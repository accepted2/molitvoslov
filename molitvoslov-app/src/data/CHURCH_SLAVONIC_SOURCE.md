## Полная церковнославянская Библия: происхождение и лицензия

Источник: **Ponomar Project / Elizabeth Bible**, 77 книг в Unicode с 151-м псалмом и 3-й книгой Ездры.

- Шрифт Ponomar: SIL Open Font License 1.1 (отдельная лицензия).

Данный репозиторий содержит копию данных, подготовленную командой
`python molitvoslov-app/tools/build_csl_ponomar_bible.py`.
Исходный текст можно получить по фиксированной ревизии выше.
Экспорт сохраняет символы Unicode и нумерацию издателя, но изменяет
структуру данных на JSON для отображения в React Native.
